# Contributing

Thanks for your interest! Quick guide:
- Clone and `make setup && make up`
- Copy `.env.example` → `.env` and adjust if needed
- Run `make demo` to see a tiny end-to-end flow
- Code style: `make fmt` (Black + Ruff), lint: `make lint`
- Tests: `make test` (add more over time)
- To add a remediation tool: keep it minimal; document inputs/outputs in the PR

Please keep PRs small and focused. Thank you!
